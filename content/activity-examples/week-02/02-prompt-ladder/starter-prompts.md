# Prompt Ladder Challenge — Starter Prompts

Use these as your starting prompt for each round. Improve it in three rounds by adding one layer at a time.

---

## Task 1: Study Explanation

**Round 1 (Base):**
Explain machine learning.

**Round 2 — Add audience + format:**
_Your improvement here: add who the explanation is for and what format to use._

**Round 3 — Add constraints:**
_Your improvement here: add a word limit, a required example, or a banned topic._

---

## Task 2: Quiz Creation

**Round 1 (Base):**
Write quiz questions about World War II.

**Round 2 — Add level + number:**
_Your improvement here: specify the grade level and exact number of questions._

**Round 3 — Add format + difficulty:**
_Your improvement here: specify MCQ/short-answer format, difficulty, and whether to include answer keys._

---

## Task 3: Writing Support

**Round 1 (Base):**
Help me write an introduction.

**Round 2 — Add topic + audience:**
_Your improvement here: specify the essay topic and who will read it._

**Round 3 — Add length + tone:**
_Your improvement here: add a word count target and a required tone (formal, persuasive, narrative)._

---

## Scoring Guide

After each round, compare the AI output and answer:
- Is the output more specific?
- Is it easier to use directly?
- What was the single most valuable addition?
