# Capstone Presentation Template — 6 Slides

Use this structure for your 2-minute showcase presentation.
Each slide has a title and bullet points to fill in. Keep text minimal — speak, don't read.

---

## Slide 1: The Problem

**Title:** [Your project name] — Solving [one-line problem]

Bullets:
- Who has this problem? (target user)
- How serious is it? (1 sentence)
- Why is AI the right tool to help?

---

## Slide 2: Our Solution

**Title:** How [project name] works

Bullets:
- One-sentence description of the system
- The main thing the user can do with it
- One AI feature that makes it different from a basic search or chat tool

---

## Slide 3: AI Features and Workflow

**Title:** What happens when a user asks a question

Show your workflow as an arrow chain:
User input → [RAG / Tools / Prompts] → AI generates response → [Human review?] → User receives answer

Bullets:
- Name the AI features: RAG, MCP, specific tools, agent layers used
- Cite one prompt example

---

## Slide 4: Agent Design (Week 6 Layers)

**Title:** How the agent is structured

Use the 6-row table format:

| Building Block | Included | What it does |
|---|---|---|
| Rules | Yes/No | |
| Skills | Yes/No | |
| Tools | Yes/No | |
| Subagents | Yes/No | |
| Plugins | Yes/No | |
| Hooks | Yes/No | |

Highlight the one building block you consider most important and explain why.

---

## Slide 5: Safety and Model Choice

**Title:** Responsible design

Bullets:
- Privacy: what data is accessed and how it is protected
- Human review: when does a human check the output?
- Model used and why (cost, quality, privacy)
- One edge case you tested and how you handle it

---

## Slide 6: What We Would Do Next

**Title:** If we had one more week...

Bullets:
- One feature we would add
- One safety improvement we would make
- One thing we learned from this project that surprised us

---

## Presentation Tips

- Practice the full 2 minutes at least twice before the showcase
- Do not read your slides — use them as memory prompts
- Be ready to answer: "Why did you choose that model?" and "What happens if the AI gets it wrong?"
- Show a real example of your system working, even if it is a paper prototype or screenshot
