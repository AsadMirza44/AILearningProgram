# Train the AI! (Sorting and Classification Game)

Use `classification-cards.csv` to run the sorting game. Start with easy examples, then add the tricky cases to show why training data and labels matter.

Suggested flow:

1. Choose one category set, such as Spam / Not Spam.
2. Show two labeled examples first.
3. Ask teams to classify the remaining cards.
4. Discuss disagreements and ask what extra data would help the pretend AI learn better.
