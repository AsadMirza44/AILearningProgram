# Prompt Battle (Talk to the AI)

Use `prompt-tasks.md` for battle rounds and `prompt-scorecard.csv` for judging. Teams should improve the prompt before the trainer runs selected prompts live.

Suggested flow:

1. Pick one task.
2. Give teams two or three minutes to write a prompt.
3. Run two or three prompts live.
4. Score the outputs using the scorecard.
5. Discuss which prompt instructions improved the result.
