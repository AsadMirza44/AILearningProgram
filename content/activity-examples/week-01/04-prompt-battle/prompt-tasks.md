# Prompt Battle Tasks

## Round 1: Lesson Plan

Task: Generate a 30-minute lesson plan for grade 7 students on photosynthesis.

Weak starter prompt:

```text
Make a lesson plan on photosynthesis.
```

Stronger prompt shape:

```text
Act as a middle-school science teacher. Create a 30-minute grade 7 lesson plan on photosynthesis. Include one learning objective, a 5-minute starter, a simple explanation, one group activity, three check-for-understanding questions, and a teacher review checklist. Use clear classroom language.
```

## Round 2: Quiz Questions

Task: Write quiz questions for a lesson on fractions.

Weak starter prompt:

```text
Write questions about fractions.
```

Stronger prompt shape:

```text
Create five grade 6 quiz questions on adding fractions with unlike denominators. Include four multiple-choice questions and one short-answer question. Provide the answer key and one common mistake each question checks.
```

## Round 3: Explain to Children

Task: Explain photosynthesis to children.

Weak starter prompt:

```text
Explain photosynthesis.
```

Stronger prompt shape:

```text
Explain photosynthesis to 10-year-old students in simple language. Use one real-life analogy, avoid advanced vocabulary, include two quick questions, and keep the explanation under 150 words.
```
