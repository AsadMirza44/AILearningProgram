# Week 4 — Python and Automation: Code Starter Files

Each folder below contains a `starter.py` file for the corresponding class activity.
Students can run these locally with `python starter.py` or paste them into Google Colab.

## Google Colab (no installation needed)

Open https://colab.research.google.com/ → New notebook → paste any starter code into a cell → press Ctrl+Enter.

For the API starter (folder 05), you will also need to add your Anthropic API key as a Colab Secret:
Runtime menu → Secrets → add ANTHROPIC_API_KEY.

---

## Activity Folders

| Folder | Activity | What students build |
|---|---|---|
| 01-calculator | Activity 2: Build a simple calculator | Variables + arithmetic + print |
| 02-quiz-app | Activity 3: Build a quiz app | Lists + loops + conditions + score |
| 03-rule-chatbot | Activity 4: Build a rule-based chatbot | while loop + elif chain + string matching |
| 04-study-schedule | Activity 5: Automate a study schedule | Lists of dicts + functions + enumerate |
| 05-api-basics | Activity 6: Call an AI API from Python | Anthropic SDK + prompt + response |

---

## How to Use in Class

1. Open the folder for the current activity on the projector.
2. Walk through the starter code line by line before students run it.
3. Students complete the TODO sections on their own machines or in Colab.
4. Compare solutions and discuss the Challenges at the end of each file.
5. For the API activity, have your API key ready or use the teacher demo account.
